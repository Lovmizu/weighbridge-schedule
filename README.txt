Weighbridge-Schedule — Offline PWA

Pembaruan identitas aplikasi:
- Nama aplikasi: Weighbridge-Schedule
- Logo: logo yang diberikan pengguna
- Tema: putih, hitam, merah
- Tetap memuat jadwal siklus 21 hari, data hari libur 2026-2027, dan pencatatan IZIN/SAKIT/ALPA/CUTI dari versi sebelumnya.

Cara pembaruan GitHub Pages:
1. Ekstrak ZIP.
2. Ganti file index.html, app.js, sw.js, manifest.webmanifest, icon.png, dan icon.svg di root repository.
3. Commit changes.
4. Buka ulang aplikasi dan refresh.

Backup data aplikasi sebelum pembaruan. Data disimpan lokal pada perangkat.
